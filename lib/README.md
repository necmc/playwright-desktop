# playwright-desktop

Esta carpeta corresponde a la librería `playwright-desktop`, que integra las acciones web de Playwright Python con interacciones de escritorio mediante un motor Rust.

El paquete se llama `playwright-desktop` y se importa como `playwright_desktop`. La API en diseño utiliza `page.desktop` sobre la clase oficial de Playwright, con Python y un motor Rust para Windows y Java Access Bridge.

- [Propuesta de arquitectura](../docs/superpowers/specs/2026-11-17-libreria-python-rust-design.md).
- [Plan de implementación](../docs/superpowers/plans/2026-11-17-libreria-python-rust.md).

La implementación aún no ha comenzado. El [README principal](../README.md) describe el uso y la sintaxis de la librería. La [demo de información del equipo](../demo/informacion-equipo/README.md) documenta su preparación, ejecución y pruebas.
